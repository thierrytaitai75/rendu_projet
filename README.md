# Projet de fin de formation – Data Analyst

## Contexte

Ce projet a été réalisé dans le cadre de la spécialisation Data Analyst.

L'objectif est d'analyser les ventes d'une entreprise e-commerce à partir du jeu de données TheLook Ecommerce afin de produire des indicateurs clés (KPI), des analyses exploratoires et un tableau de bord Power BI.

---

## Objectifs

- Nettoyer les données
- Réaliser une analyse exploratoire (EDA)
- Calculer les principaux KPI
- Produire les requêtes SQL
- Concevoir un tableau de bord Power BI
- Présenter les résultats lors d'une soutenance

---

## Technologies utilisées

- Python
- Pandas
- Matplotlib
- SQL (BigQuery)
- Power BI
- Git
- GitHub
